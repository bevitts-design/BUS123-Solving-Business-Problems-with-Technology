Count functions and their inputs

FunctionSyntaxInputs needed
COUNT=COUNT(value1, [value2], …)Numbers or cell ranges; counts numeric cells.
COUNTA=COUNTA(value1, [value2], …)Values or cell ranges; counts nonempty cells.
COUNTBLANK=COUNTBLANK(range)One cell range; counts empty cells.
COUNTIF=COUNTIF(range, criteria)One range to check and one condition.
COUNTIFS=COUNTIFS(criteria_range1, criteria1, …)A range and condition for each rule; all rules must be met.

Square brackets mark optional inputs; … means more inputs can follow. COUNTIFS ranges must be the same size and line up by row.

9 / 31

Give a range a meaningful name

Why name a range?

A name explains what the cells contain, so formulas are easier to read, reuse, and check.

=COUNTIF(OrderRegion,"North")OrderRegion means the region values in Orders!B2:B7.

Choose the name from the Name Box dropdown to jump back to those cells.

How to create it in Excel

  1. On Orders, select B2:B7; leave out the header.
  2. Click the Name Box to the left of the formula bar.
  3. Type OrderRegion and press Enter.
  4. Open Formulas → Name Manager. Verify workbook scope and =Orders!$B$2:$B$7.

Repeat: OrderStatus = C2:C7; OrderSales = D2:D7. Start names with a letter or underscore; no spaces or cell addresses. Extend fixed ranges when adding rows.

In Orders!G8, total the Sales amounts for every North order, including Open and Closed orders.

=SUMIF(range, criteria, [sum_range])Check a range against one condition; add the corresponding values.
InputWhat it meansOur example
rangeCheck each order’s regionOrderRegion · B2:B7
criteriaThe condition to match"North"

See the worked example

=SUMIF(OrderRegion,"North",OrderSales) → $470: TG01 ($120) + TG03 ($200) + TG05 ($150).

Cell styles make a workbook easier to read

A cell style is a reusable set of formatting: font, fill, borders, and number format.

Why use them?

Consistent styles help a colleague recognize what to enter, what Excel calculates, and which results support a decision.

Input → selected order ID

Calculation → looked-up region

Output → contact for follow-up

Use the same style for cells with the same purpose.

How to apply a style in Excel

  1. Select the cell or range.
  2. Open Home → Cell Styles.
  3. Choose a style, such as Input, Calculation, or Output.
  4. Check that the labels and number format fit the data: dollars, counts, or text.

Styles change appearance, not values or formulas. Keep clear labels; do not rely on color alone. Workbook themes can change how built-in styles look.

Prepare the source as an Excel Table

An Excel Table organizes a data range with headers, filters, and a name. It is the source for our PivotTable summary.

Create and name the table

  1. Select 'Pivot Practice'!A1:D7 only.
  2. Choose Insert → Table; confirm My table has headers.
  3. Click inside the table. On Table Design (or Table), set Table Name to OrdersData.

Table ≠ PivotTable

Excel Table: the individual orders.

PivotTable: a grouped summary of those orders.

A growing Table can include new rows; refresh the PivotTable to update its summary.

Keep one header row, one order per row, and no merged cells or total rows in the source. A named range labels cells; an Excel Table also adds data-management features.

ToolWhat it doesHow to use it
