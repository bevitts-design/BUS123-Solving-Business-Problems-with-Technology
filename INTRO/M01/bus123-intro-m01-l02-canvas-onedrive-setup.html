Before you begin

1. Your Windows laptopConnected to the internet
2. Your full emailYourName@mail.endicott.edu
3. Your credentialsEndicott password and verification device, if prompted
Follow these steps

Connect your Endicott OneDrive

1

Confirm your Endicott Microsoft 365 sign-in

  1. Select Open Microsoft 365.
  2. Select Sign in and enter your full @mail.endicott.edu email address.
  3. Complete the Endicott sign-in and any verification prompt. If asked, select Work or school account.
Success looks like: you see Microsoft 365 apps connected to your Endicott identity.
2

Open the OneDrive desktop app in Windows

Windows

Open Start, type OneDrive, and open the desktop app. OneDrive is built into current Windows versions; use the Microsoft download button above if search finds nothing.

3

Connect the app to Endicott

  1. In the OneDrive setup window, enter your full @mail.endicott.edu address and select Sign in.
  2. Complete the Endicott sign-in. Choose Work or school if Microsoft asks you to choose an account type.
  3. Keep the suggested OneDrive folder location unless you have a specific reason to change it.
  4. Continue through the setup screens, then select Open my OneDrive folder or Open OneDrive folder.
Already using a personal OneDrive? Open the OneDrive cloud icon, open Settings, go to Account, and select Add an account. Add Endicott as a separate work or school account.
4

Find the synced folder in File Explorer

The organization label normally includes Endicott. The exact wording can vary slightly.

Windows: File Explorer
Navigation
☁ OneDrive – Endicott
OneDrive – Endicott
📁 BUS123
📄 Sync Check
Press Windows key + E and look in the left navigation pane. If it is not visible, open the OneDrive cloud near the clock and choose Open Folder.
5

Create your BUS123 folder and prove it synced

  1. Inside OneDrive – Endicott, create a folder named BUS123.
  2. Inside BUS123, create a new folder named Sync Check.
  3. Wait until the circular syncing arrows disappear. A blue cloud or green check beside the folder is normal.
  4. Open Microsoft 365 online, open OneDrive, and confirm that both folders appear there.
Finish line: You can see the BUS123 folder in both places—on your computer and in OneDrive on the web.
Read the symbols

What the OneDrive status icons mean

☁
Blue cloud Stored online; downloads when you open it
↻
Circular arrows Sync is still in progress; wait
✓
Green check Downloaded and available on this device
✕
Red X Sync problem; open the cloud icon for details

Icon appearance can vary slightly by operating-system version. The reliable final check is seeing the same folder in OneDrive on the web.

Avoid this

Common setup mistakes

  • Creating a new personal Outlook or Hotmail account
  • Signing into OneDrive – Personal instead of Endicott
  • Using OneDrive only in a browser without connecting the desktop app
  • Saving course work to Downloads or Desktop by accident
Quick fix

If the Endicott folder does not appear

  1. Open the OneDrive cloud icon near the Windows clock.
  2. Confirm the account shown ends in @mail.endicott.edu.
  3. If it does not, open Settings → Account → Add an account.
  4. If a red X remains, contact Endicott Campus Technology.
Using a Mac instead?

The sign-in is the same. These controls are different.

Use the same Endicott email, work-or-school account choice, folder name, and online sync test. Replace the Windows actions above with these Mac actions:

Open OneDrive Press Command + Space, type OneDrive, and open the app.
Find your files Open Finder and select OneDrive – Endicott under Locations.
Check sync Use the OneDrive cloud in the top menu bar. Choose Open Folder if OneDrive is missing from Finder.
