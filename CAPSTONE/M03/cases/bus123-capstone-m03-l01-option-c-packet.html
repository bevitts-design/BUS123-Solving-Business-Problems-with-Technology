Which proposed portfolio fits the client’s risk limits while giving the client an opportunity for growth?

Download the Excel starter · View the shared rubric

Business context

A client has $100,000 and wants a one-year comparison of two proposed allocations using the same 12 fictional investments. The client wants growth and has specific limits on concentration and downside loss.

Options. Growth mix and Balanced mix.

Case data and assumptions

The 24 records are included in the workbook’s Inputs tab. The same records are linked to the CaseAnalysis table on the Analysis tab. Preserve the given option and row order.

AssumptionValueHow to use it
Amount to invest$100,000Both options should fully allocate this amount.

Maximum modeled downside loss8%Modeled downside return should be at least −8%.

Build the model and verify it

  • Base and downside returns are the supplied hypothetical one-year total returns, with income included. Apply each holding’s same scenario rates to both options. Use dollar allocations to calculate weights and return contributions.
  • Assign each holding to its stated asset class and use the largest total class weight as the concentration measure. Do not estimate the holdings inside each fund.
  • Assume no fees, taxes, trades, or rebalancing during the year. These scenarios are provided for comparison. They do not establish a probability or expected future outcome.
  • Complete the outputs on Analysis and Summary. Show an independent result for growth mix base portfolio return and a check of balanced mix total portfolio weight. Record your method, comparison and conclusion on Summary.

Summarize and visualize

  • PivotTable 1 • Rows: Group (asset class). Columns: Option. Values: Sum of portfolio weight.
  • PivotTable 2 • Rows: Option. Values: Sum of base return dollars and sum of downside return dollars.
  • Chart the base and downside portfolio return for both options. Build a second chart from PivotTable 1 that compares the options across asset classes. Exclude grand totals from chart series.
  • Format currency, percentages, and counts appropriately. Use clear headers, readable column widths, consistent precision, meaningful titles, and labels or legends that identify the cases or series.
