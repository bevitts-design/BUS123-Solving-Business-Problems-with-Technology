Error diagnosis · two different failures

Excel may flag the syntax. It may miss the logic.

Visible syntax problem

Excel interrupts you

=SUM(C8:C11

Missing parenthesis. Excel can usually identify the malformed expression.

Silent logic problem

The formula runs—but omits a row

=SUM(C8:C10)

No error code appears. The range check reveals that Emergency in C11 is missing.
